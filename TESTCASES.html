TRƯỚC KHI BAY

Chạy project ở local

Làm đủ 6 bước này rồi mới chạy checklist. Mọi thứ bind vào localhost — đây là công cụ một người dùng chạy trên máy mình, không phải service để expose.

Windows: các lệnh dưới viết cho Git Bash (shell mà repo này dùng). make có thể không có sẵn — cứ chạy thẳng lệnh tương ứng.
1

Cần có sẵn

Python 3.11+ · Node 18+ · Docker Desktop (để build PDF LaTeX) · PostgreSQL 17 (bản cài trên máy, hoặc dùng compose).

# kiểm tra nhanh
python --version && node --version && docker --version && psql --version
2

Cài dependency

Các extra là opt-in để bản cài tối thiểu vẫn nhẹ. all lấy hết.

pip install -e '.[all,dev]'
playwright install chromium   # chỉ cần cho ITviec / VietnamWorks
3

Tạo .env ở gốc repo

Copy từ mẫu rồi điền. File này đã gitignore — không bao giờ commit.

cp .env.example .env
DATABASE_URL=postgresql+psycopg://postgres:<mật khẩu>@127.0.0.1:5432/jobpilot
JOBPILOT_API_TOKEN=<chuỗi bất kỳ, dùng để gọi API>
ANTHROPIC_API_KEY=          # chỉ cần cho phase 5 (tailor)
IMAP_USER=/IMAP_PASSWORD=      # chỉ cần cho nguồn LinkedIn alerts
4

Tạo DB và migrate

psql -U postgres -c "CREATE DATABASE jobpilot;"
alembic upgrade head        # tạo schema `jobpilot`

Hoặc chạy Postgres trong Docker: docker-compose up -d postgres.

5

Chạy backend + dashboard

# terminal 1 — API + WebSocket
uvicorn jobpilot.api.main:app --reload --port 8000

# terminal 2 — dashboard
cd web && npm install && npm run dev

API ở http://127.0.0.1:8000 (docs tự sinh ở /docs), dashboard ở http://localhost:5173. Trang: Dashboard · Jobs · Job detail · CV Review · CV Studio · Applications · Runs · Settings · Guide.

6

Lấy token để gọi API bằng curl

Mọi route trừ /health đều cần bearer token. Đặt sẵn biến để dùng lại cho cả checklist:

TOKEN=$(python -c "from jobpilot.config import get_secrets;print(get_secrets().jobpilot_api_token)")
curl -s -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8000/stats

Có dữ liệu để test: bấm Crawl now ở trang Runs, hoặc

python -m jobpilot.cli crawl --query "java" --limit 10
Query phải ngắn. Nó thành slug/từ khoá ở từng site. "java spring boot backend" làm TopCV trả về 0 job (và crawl sẽ cảnh báo đúng như vậy).
Nguồn sự thật của tài liệu này: PLAN.md (kiến trúc), SKILL.md (luật tailor), CLAUDE.md (bug đã gặp khi chạy thật + test ghim tương ứng). Case gắn nhãn tự động đã có test trong jobpilot/tests/ — chạy tay chỉ để xác nhận trên môi trường thật.
